# 可操作的视觉工作台

项目页第二台装置把原 Flask 项目的 MTCNN 检测器接入浏览器：示例或本地照片实际经过 P-Net、R-Net、O-Net，候选框和五个关键点由模型计算，再驱动同一三维工作台。它展示检测与定位，不实现 FaceNet 身份匹配，也不运行原 Flask 服务。原项目卡片、源码和实现笔记入口保留。

## 数据与计算

[模型清单](../../assets/vision/manifest.json) 固定原仓库提交 `630512dacf9715d4bb5a798814bf6282b34a5417`。三份 H5 的 50 个 float32 权重张量按原字节导出为 1,983,400 字节；没有量化、重训或加入私人训练照片。每个张量记录名称、形状、偏移和 SHA-256，原模型文件摘要与 MIT 许可一并保留。

TFJS core 与 WASM backend 固定为 4.22.0，使用单线程 WASM，支持时选择 SIMD。五个运行文件共 1,615,283 字节，实际只下载适用的 WASM 文件。首次按“开始检测”才创建 Worker 和载入运行时、权重；主线程继续处理交互。重复检测复用 50 个权重张量，中间激活释放；停止计算或离开项目页终止 Worker。模型下载验证长度与 SHA-256，失败给出可重试提示。

输入限定 PNG、JPEG、WebP，最多 20 MB、3200 万像素，解码后保持比例缩至最长边 512。两边均需至少 24 像素，过窄图明确拒绝；透明像素合成白色。照片通过内存传给同源 Worker，不发出图片或结果上传请求。原项目的数据集与结果照片没有发布到网站。

实际运算保留原项目的 RGB 归一化、0.709 尺度因子、P/R/O 阈值 0.5/0.7/0.8 和 NMS 阈值 0.7/0.7/0.3。R/O 的 flatten 使用原 Keras 的 N,C,W,H 顺序；边框回归的两轴都乘原框宽度，按原实现保留。浏览器增加退化裁切检查与 6000 候选上限，超限给出错误，不以截断结果冒充完整检测。WASM 与 OpenCV/NumPy 有浮点差异，不声称逐位一致或与原 Keras 运行完全相同。

示例为 NASA 公开照片的 scikit-image 0.25.2 原 PNG，512×512、791,555 字节。界面链接原 NASA on The Commons 页面，信用说明取自来源元数据；没有从照片推断身份，也不把它作为网站品牌或代言。来源详见[公开核验](public-references.md#真实的浏览器人脸检测)。

## 连续动作

三种项目装置共用原底座、渲染器与 Mote。改选从当前升降比例接续，角色沿锚点移到实际摇柄，手部位置转换包含底座旋转和当前响应式缩放。检测完成后进入八拍演示：实际尺度试片展开，P-Net 候选长出，R/O 按候选 ID 保留并修正框，淘汰框收拢，最后五点出现并连续放大对应人脸区域。

照片 UV 与标记坐标共用缩放和偏移，标记保持可读的屏幕尺寸；框与点来自同一模型结果。旧框、点和照片取景在再次运行时连续回收。停止演示保留当时试片和摇柄姿态；空白图返回真实的零检测。固定候选缓冲、12 个尺度平面、同一照片纹理及标签图集重复利用，不逐帧创建贴图。

开启音乐时，在推理结束后读取当前音乐时钟，等待下一整拍起步；其后使用界面单调时钟推进，暂停声音仍能结束。减少动态效果直接显示结果。无 WebGL 时同一 WASM 检测仍运行，使用带框和五点的二维画布与文字结果。三维空间中的动画用于解释计算流程，实际推理发生在演示开始之前。

## 复现与边界

`tools/pack-vision-models.py` 接收固定版本原仓库、TFJS npm 包、原示例和上游许可路径；`validate:vision` 检查权重、运行时、图片摘要、张量形状与连续偏移。它已纳入全站 `validate`。

`tools/reference-vision.py` 直接读取原 H5，使用独立 NumPy 卷积/池化/PReLU/全连接与原 Python 后处理、OpenCV 缩放，生成提交的参考数据。完整照片以及 320×512、512×320 两个左上裁切用于检查非正方形坐标。参考不导入浏览器实现，也不运行原 Keras；小数误差可能交换两个相近分数的行，因此逐行要求唯一几何匹配并比较置信值和关键点。

运行命令和专项范围见 [Web harness](../harness/web/README.md)。桌面 Chromium 的模拟手机视口、数值比较和无音轨录像不能代替真实手机、辅助技术、配乐听感和用户艺术验收。
