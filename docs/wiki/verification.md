## 第四轮：房间 HDR 烘焙与去噪

## 第六轮：连续物件探索与可读性

用户再次强调避免通用游戏蒙太奇与静态幻灯片。房间探索改为同一 Mote 从实时位置沿弧线飞向物件，逐渐缩小并靠近观察；途中改选从当前状态继续。相机的 viewOffset、虚拟高度及位置同时过渡。进入内容世界的聚拢承接当前角色状态。音乐开启时在半拍边界起步，移动两拍；音频系统中断后交互仍完成，减少动态效果会立即终止飞行动画。

桌面、短屏及启用声音的手机视口，真实浏览器检查选择物件瞬间的位置与投影矩阵无跳变，中途改选、返回尺寸、音频中断与减少动态效果均通过。进一步复现了揭示尾帧从静止锚点切回呼吸位置的 0.06853 世界单位回跳；改为随当前休息姿态结束揭示，冻结时间的同一复查差为 0.00000312。转场位置检查扩展了尾帧连续性。

首页标题后增加局部暗部，顶部导航和章节入口有稳定文字背景，提高说明文字的亮度。三种色调、桌面与手机的六个冻结视图，保守采样字符框中的背景：大字最低约 3.53:1，小字最低约 5.44:1，采样均超过对应参考阈值。采样保留导航底板，使用 CSS 的完整文字颜色而非抗锯齿像素；此项不是全站、所有帧或所有设备的 WCAG 合规声明。方法来源见 [W3C 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。
