# 验证记录

## 2026-10-03 首个可运行版本

范围：55 个 HTML 页面。`npm run validate` 核对全部本地资源、入口、import map、脚本语法、实验脚本类型，以及 39 篇文章正文与 `8485a72` 基线。唯一正文链接变更为已核实的 openEuler 官方 ISO 地址。

`npm test`：7 项通过，包括路由/节拍、存储拒绝、PCM 数据与确定性、实验接入重复执行的回归场景。

`npm run test:browser`：桌面 1440×1000 和手机视口 390×844 的 110 次连续切页、55 次直接访问、9 个行为场景均通过。全部页面没有横向溢出，渲染器与 canvas 身份保持一致。九个原始实验分别实际执行并绘制。

随后复查了房间引导与 Escape 返回，以及减少动态效果下实验等待用户主动开始。二者通过；实验的静态 canvas 元素可提前存在，动态脚本在点击开始前不会载入。

行为检查包含原创音乐的实际启动、有限且非零的采样输出、暂停/恢复与跨页音频上下文连续性；文章搜索/标签/复制/锚点；前进后退、连点、失败恢复；皮肤持久化、GPU 分配不增长；手机导航；存储拒绝、减少动态效果与键盘；WebGL 和房间模型失败降级。

环境：Windows / Node.js 22.23.1 / Chromium 151.0.7922.10 / AMD Ryzen 9 7945HX / NVIDIA RTX 4060 Laptop GPU / ANGLE Direct3D11。手机结果来自桌面浏览器视口模拟，不能等同真实手机性能。

截图迭代：已保存基线与三轮主页面桌面/手机截图。修正玻璃高光、手机主体与标题遮挡、书页文字镜像、长代码溢出及唱机尺寸；增加接触阴影与本地字体。临时 PNG 与完整 JSON 保存在忽略目录，便于继续比较。

静态房间合并：813 个 mesh 减为 135 个；桌面绘制调用由 1627 减为 273，三角形保持 333039（含当前后处理统计）。这是绘制调用的测量，不是帧率改善声明。新增程序化场景加入阴影后，主页面约 86–164 次调用。

独立帧间隔检查：每个主页面采集 120 个预热后的 RAF 间隔。桌面渲染比例 1.6、手机视口模拟比例 1.25，间隔中位数约 9.5–9.7 ms，95 分位约 10.1–10.4 ms。该数据是当前机器的浏览器帧调度间隔，不是独立 GPU 渲染耗时，也不能推断真实手机帧率。
