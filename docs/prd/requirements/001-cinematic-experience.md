# 001 全站电影化体验：实现规格

## 范围与不变量

- 全部 55 个现有 HTML 路由：房间、6 个板块、39 篇文章、9 个实验。以最终路由清单核对，不能仅检查首页。
- 保留既有个人资料、项目链接、文章原文、搜索/标签/目录/代码复制、实验玩法和皮肤持久化。
- 每个内容入口具有专属 3D 主体、光照、构图与叙事运动。文章详情与实验详情同样具有一致的模型和转场覆盖。
- 用户再次明确要求避免通用游戏蒙太奇和静态幻灯片。物件反馈、角色移动与内容揭示须有可理解的因果关系；房间特写从当前相机和角色状态接续，途中改选目的地也保持连续。
- 新的文字导航、静态正文、失败降级和键盘路径随时可用。

## 空间与导航

- Three.js 0.185.1 为既有基准；运行所需模块本地托管，依赖版本一致。
- 主渲染场景与声音在受支持的站内导航过程中保持连续；路由支持直接访问、刷新、前进/后退、锚点和失败回退。
- 并发点击、资源延迟、WebGL 不可用和恢复过程中不能留下遮挡层或永久加载状态。
- 房间模型以字节流报告下载进度，连续传输可以超过 18 秒；30 秒无数据或总等待 120 秒时取消。下载中切换板块保持导航可用，返回后恢复真实加载状态且不重复请求。光照图处理完再显现导入模型。
- 光照图通过保持原始图片字节的资源包传输，校验索引范围和逐图摘要；资源包不可用或单张损坏时能回退原图，保留原 UV、尺寸与 HDR 倍率。回退请求有并发和时间上限，生成包必须与当前 manifest 源图一致。
- 每个场景正确释放独占 GPU 资源；切页后输入监听、时间线与渲染器不能重复累积。
- 文章列表的书页从原目录提取真实标题、日期、标签与路径。翻阅实体纸页选择下一篇，界面链接对应同一条目；直接访问与 SPA 进入得到相同路径。键盘和触控入口等效，空白处不触发翻页，连续输入不会重置正在翻动的纸页。暂停声音仍可操作，减少动态效果立即换页；文章详情保留当前文章，动态纹理及时释放。
- 项目工作台基于原 C++ 聊天室资料，以本地流程演示说明消息经过中转台送达其他终端。用户输入与三端屏幕一致，发送中不能覆盖或切换发送端，空消息不启动；提供键盘、实体命中与可访问状态。原三项目、全部仓库入口与实现笔记保留，不伪造后台连接。复用 GPU 屏幕纹理，离开页面取消本次传送和订阅。
- 皮肤页以同一首页房间作为实时配色预览；五块实体样本、键盘按钮与下方卡片同步。换色从当前状态连续改向，音乐暂停也会结束，减少动态立即应用。预览与首页共用配色规则、几何和光照，但材质独立；离开只释放预览独占资源。下载中选择、返回首页与重试保持当前选择和真实加载状态。
- 关于页依据原文的跑步、游泳和偶尔下棋，让同一角色在连续活动台内运动；按钮与实体命中等效，途中改选保持姿态连续，暂停声音仍能完成。水波由角色实际游泳位置驱动，落子时手跟随棋子；一拍进入、六拍活动、一拍返回与启用的配乐衔接。窄屏预留完整动作范围，离开恢复共享角色姿态并释放独占实例/材质资源；不虚构个人经历、具体棋种或棋力。
- 海洋首屏与驾驶区复用船体和波浪定义，船身取样实际波高，帆与阴影同形变；首屏选择风力可带入驾驶。保留 W/S、A/D、拖拽，并提供触控/键盘船舵与输入取消；减少动态先征得访客主动开始，离开视野暂停实验绘制。波浪取样与着色器一致，不宣称完整海洋或水动力仿真。

## 动画与声音

- 动画包括程序化几何/粒子、排版运动、角色表演、光照和空间转场；母题随内容发生有意义的变形。
- 逐采样生成原创 PCM 配乐：有完整旋律、和声、低音、鼓与电子音色，包含动漫式活力及游戏声音质感。
- 以同一节拍与情绪时间线协调揭示、标题、相机、角色和声音事件。静音与暂停状态明确。
- 声音仅在用户手势后开启，有持久的关闭与音量控制；自动播放失败可以恢复。
- 当前配乐为 112 BPM、32 小节四乐章；采用按设备生成的 32/24 kHz PCM。完整输出和重叠提示音经浏览器音频图渲染验证，晚启动保留时间位置，暂停/恢复与切页不重复创建持续声部。
- 转场圆心与共享粒子的聚拢点来自角色实际发光点，桌面、移动视口及房间特写均核对位置。
- 系统暂停 AudioContext 后保留当前叙事位置，控制显示继续播放；手势恢复同一组音轨，不能回到会话旧时间或需要额外一次暂停操作。
- 角色的自然眨眼沿独立界面时钟完成，配乐暂停或系统中断不能使其长期闭眼；减少动态效果保持稳定睁眼，不启动额外动画循环。配乐驱动的脉冲与节拍继续沿原声音时钟。
- 电台唱机可通过唱片实际命中、键盘或按钮控制同一配乐。唱片仅随实际运行的音频时钟转动，暂停抬针并保留转角；唱针沿循环进度行进，归位保持连续。四个声部可独立开关并保存选择，切页仍保持当前混音和原音轨身份。表针使用声部采样电平，暂停、全静音与减少动态效果有稳定状态。
- 竖屏构图以实际文字高度安排模型，覆盖短屏与平板；滚动、字体载入、窗口改变和房间特写不造成标题遮挡或投影失配。
- 电台音波从实际喇叭口坐标系发出，跟随模型姿态和窄屏缩放，四组粒子对应当前声部电平；静音、暂停和减少动态效果不假装发声。文章与项目不保留脱离现有模型的旧排版阵列或柱体轨迹，转场继续复用共享粒子几何。
- 唱片刻纹采用随距离过滤的材质细节，避免细圆环几何在旋转时形成明显干扰纹；三道分界与四乐章和唱针半径一致。新增模型纹理独占并在离开时释放，共享通道贴图不重复释放。
- 药瓶反应在单调交互时钟上完成，开启声音时等待半拍起步、持续两拍；配乐暂停或系统中断不能把瓶塞卡在半空。点击实际瓶身/瓶塞或键盘按钮等效，连点只续接一次且不跳变，离开时清理队列，减少动态效果立即恢复静止姿态。
- 药瓶以连续曲线构成通透玻璃，阴影不能污染透射背景。液面扰动、瓶内气泡和瓶塞沿同一反应进度推进，结束后消散；不保留与反应无关的常驻双螺旋。反应资源复用并在离开时释放，窄屏保持气泡与瓶身的相对比例。

## 工程与验证

- 单个手写源码文件不超过 500 行，按叙事、渲染、声音和编排职责拆分。
- 继续兼容 GitHub Pages。需要的构建和验证命令有入口，不依赖未记录的本地软件。
- 基于桌面和手机实际截图迭代构图，不能只用文件存在或 JS 无语法错误证明视觉质量。
- 记录测试设备、帧时间、资源体积、加载、运行错误和声音同步数据。性能未测量不能声称改善。
- 有意义的独立改进及时提交推送；最终上线验证发布内容、所有路由和关键行为。
