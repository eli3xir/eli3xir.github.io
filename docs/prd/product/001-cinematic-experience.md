# 001 全站电影化体验：产品验收

本页是验收范围，不是完成声明。验收记录必须提供实际截图、测量、测试与提交依据。

1. 进入首页：房间清楚、构图具有吸引力、加载后可环视；可用物件可辨识，键盘和文字入口可抵达全部板块。模型失败时仍可阅读和导航。
   慢速下载时可看到进度并先去阅读文章；返回房间延续同一次下载，准备完成后才显示已就绪。持续传输不会在旧的 18 秒期限被取消，真正停滞可退出；光照未完成时不闪现过亮模型。
   正常传输完整载入房间光照；资源包或其中一张图片损坏时，可从原图恢复，画面与皮肤选择保持一致。
   关于近景能看见本站主人的公开账户头像与署名，画框能看见五种网站配色；角色不覆盖画框标题。头像缺失或损坏仍可浏览和进入关于页。进入皮肤后，缩微房间保留相片和色样，指针随选择连续移动，途中改选不跳回起点；模型加载前先选也正确显示，回到首页与最终选择一致。实际查看桌面、窄屏画面，自动化通过不代替视觉验收。
   项目留言板可点选聊天室、人脸识别和编译器便签，也可使用按钮和键盘靠近同一张纸；名称、说明、选中状态与进入链接一致，链接直达原项目卡片。快速改选及音乐暂停保持运动连续，角色完整留在房间内，镜头不穿过顶面。关闭后没有遗留物件提示；横屏的项目选择、前后切换、进入及声音控件可独立命中。缩微房间保留同一纸面，正文与仓库链接不改动。
2. 实验室：独立药水装置和活跃的灵感角色参与介绍；9 个实验可进入、运行并返回。手机操作可完成主要体验。
   点击瓶身/瓶塞或用键盘按下“试一次反应”，瓶塞连续升起、晃动后落回；暂停声音也会完成。空白背景不触发反应，连续点击不让姿态重置；减少动态效果保持静止，离开后不会再发生排队的反应。
   瓶身呈现圆滑、通透的玻璃，能看清液面与瓶颈空间；反应时液面扰动、气泡升向瓶口并消散，结束后恢复平静。桌面和手机构图中气泡均来自瓶内，不用常驻螺旋替代反应。
   海洋实验中，先改变风力，观察船身随水面倾斜、帆面鼓起，再进入驾驶同样外观的船。选定风力保留，W/S、A/D、拖拽和触控船舵可用；取消长按不会遗留输入。回到首屏时驾驶画面暂停绘制，再进入能继续。减少动态先显示开始入口，无 WebGL 给出可读说明。
   粒子文字中，写下自己的话，光点排成同一句；按实体键或“打散再聚合”可观察连续重组。带入下方实验后继续编辑，返回首屏时文字一致；鼠标或手指拨动后松开，光点归位，取消触控不会遗留斥力。中文输入法、键盘、12 字限制与空白提示可用，快速连续操作不丢文字，减少动态和无 WebGL 仍可读写。
   登月实验中，按按钮或实体着陆器开始最后进近；向下靠近后继续同一位置和进度，返回首屏不从头播放。观察四脚垫接地、月尘散去与旗杆展开，旗面没有持续风摆；拖拽、方向键和 Home 可用，再来一次恢复待命。暂停声音仍完成，快速往返不倒退或重复着陆，离屏不持续绘制；减少动态与无 WebGL 有明确入口或说明。
   流体实验中，选一色，按按钮或玻璃位置滴入；下移后拖动同一片颜色，回首屏仍保留涡旋。暂停后滴色仍可用，清水真正清空，方向键的落点可见；触控取消不会遗留拖动。快速往返不重置颜色、流速和压力，离屏不绘制；手机说明与按钮不被画布覆盖。减少动态先显示静态玻璃，无浮点或无 WebGL 仍可选色和混色。
   星轨实验中，选择一、三或六小时，按相机或按钮开始曝光；九百颗星沿相同角速度留下弧线，偶有流星进入照片。暂停、方向键、拖动天极与重新取景可用，上下区域延续同一次曝光；选下一张时长不会改掉已拍照片。完成后照片留在装置里，关闭声音仍完成，离屏停止绘制；减少动态直接获得照片，无 WebGL 保留可操作平面观测图。
   银河实验中，六万颗星构成同一片立体星盘，点击滤光轮或波段按钮，星光与尘埃连续显现；转到侧面能看见薄盘。拖动、滚轮、双指缩放、轻推加速及键盘可用，暂停只停止转动；往返首屏保留波段、转角与视野，不重新播放。Mote 的手跟随实际轮柄，说明明确标注着色示意。减少动态保持静态并允许明确操作，无 WebGL 提供简化平面图；离屏停止绘制，手机按钮不遮挡画布。
   玻璃实验中，移动透镜看纸面，盖章、换色或增加发现；进入实验后继续操作真实按钮，返回首屏保留变化。透镜下的按钮可直接点击，固定透镜不锁纸面；三张便签在手机里完整可读。方向键、Home、空格和触控取消可用，Mote 移动时仍握住手柄；暂停声音照常盖章，快速往返不重置状态。减少动态有主动入口，无 WebGL 保留 DOM；不支持 SVG 折射时清晰模式仍可操作。
   打砖块中，移动挡板接住真正回弹的球，砖块被击中后留下缺口，漏接扣除机会，打完或机会用尽后可重开。向下靠近和返回首屏延续同一局，暂停精确保留球、挡板和尾迹；Mote 始终握住连杆。鼠标、触控、方向键、空格发球、P 暂停和 R 重开可用，触控取消不遗留输入；音频关闭或中断不冻结球。减少动态先主动开始并关闭碎片、尾迹，无 WebGL 仍能玩同一规则，手机说明与控件不遮挡球场。
   弹幕实验中，Mote 驾艇穿过同一发射装置的螺旋、花瓣和瞄准弹；白点、擦弹圈及保护圈可辨认。一次擦弹只得一次分，受击扣机会并暂时保护，机会用尽停止，重来清空旧弹。鼠标、方向键、Shift 微调和相对触控拖动可用，手指按下不把玩家传送到手指下；取消或失焦不遗留移动。上下往返保留每颗弹、得分和保护时间，暂停后位置稳定；关闭音乐仍有完整玩法。减少动态先主动开始并关闭额外擦弹波纹，无 WebGL 保留同规则平面场地，说明与控件不覆盖玩法。
3. 文章：档案/书页世界清楚对应阅读；搜索和标签可使用；全部文章标题、原文、代码、图片和数学公式保留；目录、锚点、复制和返回有效。阅读区文字不会被粒子遮挡。
   在目录首屏点击书本或使用翻页按钮，卷起的当前页露出下一篇真实标题，落页后阅读链接同步更新；连续点击保持翻页连贯。空白背景不换文章，声音暂停时照常翻阅，减少动态效果直接切换。进入详情只展示本篇，返回目录保留全部 39 篇列表。
   在文章详情看到真实标题、日期、章节和原文摘录；Mote 抓着纸角翻到下一节，松手返回后接住下一页，动作结束不跳变。点击当前章节进入对应正文，键盘焦点与手机目录可用；阅读到后文再返回首屏，书页对应当前位置。直接打开章节链接并延迟加载本地图，目标仍留在同一位置。七篇无小标题短记可直接阅读，只有一个标题的数学文章也能渲染公式。旧外部图床的失效提示不能冒充恢复成功。
   恢复的图示须实际解码、内容与相邻段落对应，桌面及窄屏比例正确且不横向溢出，出处可访问。六篇中 67 处原图均须与固定仓库提交的 Git blob 及本地 SHA-256 一致，包括两张 MTCNN 图；数据链路层延迟加载的 26 张图另核验定位。原文、重复图片位置和代码保留，纠正后的 CRC 说明及原卷积裁切可放大阅读。
   点击扫描图中的细节后可放大查看，在整图和原尺寸之间切换，拖动或滚动读到边缘；手机旋转后仍可操作，关闭回到原来的正文位置。键盘进入、双向 Tab、方向键和 Escape 有效，查看时背景控件不可误触。加载中关闭不突然重开，图片失败可返回来源提示，切页不遗留遮罩或滚动锁。原图细字与真实手机触控仍须人工评审。
4. 电台：可开启原创逐采样合成配乐；四个乐章包含冒险、留白与回应，音色、旋律、鼓组与场景动作有可感知的关系；静音、音量与恢复有效。晚启动及系统暂停没有时间重置，一次手势恢复原音轨，进度随实际乐章变化。筹备中的节目保持真实状态。
   点击唱片或播放按钮启动；暂停后唱片保持转角、唱针抬起，继续播放不重新合成。独立关闭氛围、低音、旋律、节奏能听到相应变化，全部关闭实际输出静音；电平表随采样信号响应，切页和刷新保留声部选择。减少动态效果停止唱片与表针运动，无 WebGL 仍可播放和调节。
   音波贴着喇叭开口向外传播，切换尺寸和滚动时仍来自同一实体位置；关闭声部削减对应音波，全静音和暂停时音波消失。项目线路只在实际传送时显示消息，文章动作对应真实翻页。
   唱片近看有细密刻纹与乐章分界，远看和旋转时不出现明显扇形干扰；表面保持黑胶质感，反光不抢走文字和唱针的注意力。
5. 项目与关于：3D 模型解释项目信号与个人兴趣，具有简洁的幽默表演；全部已有公开资料及外部链接保留。
   项目首屏标明本地通信演示，选择 A/B/C 终端并输入消息后，观察文字从发送端经中转台到达另外两端。空白背景不改发送端，发送中不能覆盖，暂停配乐仍能完成；减少动态效果和无 WebGL 保留文字结果。项目仓库、实现笔记和全部项目入口可达。
   关于首屏中，同一 Mote 可以沿跑道跑一圈、游一程或伸手落子；按钮与实际物件都可触发，改选时从当前动作接续，结束后返回原处。水面只随实际游泳产生波纹，手和棋子保持接触；开启配乐按拍进入与返回，暂停也会完成。各尺寸下整个动作不遮挡文字，进入其他板块后角色恢复常规姿态。原个人介绍和联系方式始终可达。
   游泳时能看到池底瓷砖与划水的连续反馈；手掌推动的水波留在经过的位置，改选跑步后逐渐消散。途中点击引起的表情与双臂不能互相拉扯。检查真实手掌到扰动轨迹的距离、池底可见像素、不同更新频率、长时间缺帧、反复操作及资源释放；减少动态应清零余波，即使媒体变化回调未送达也能完成。桌面与窄屏恢复同一冻结波形后还能游泳；固定帧比较、桌面计时均不能替代正常连续观看和真机验收。
6. 皮肤：按钮支持触控和键盘，立即预览和持久化；返回首页后材质/灯光/界面体现选择。
   首屏的样本台展示同一间真实房间，点击五块色样或文字按钮可观察材质连续变化，途中改选没有突然跳色。下方卡片同步，回到房间与预览一致；暂停音乐仍完成换色。预览未载入时可以先选，返回首页不会卡住加载提示；失败可重试，无 WebGL 仍可选择。反复进出不会重复下载或误释放首页资源。
7. 全站转场：每个现有路由均被覆盖；视觉、排版、角色与启用的配乐同步；直接访问、刷新、浏览器历史、连点和加载失败不产生黑屏或锁死。
8. 视觉评审：逐板块检查电影布光、主体与背景层次、冲击性构图、精致排版、复杂程序化运动和粒子叙事。禁止以静态幻灯片、通用游戏蒙太奇或同一个无关背景代替专属设计。
   连续探索房间，观察 Mote 飞往物件、途中改选与返回；角色、相机和空间保持连贯，动作推动下一步探索。逐板块检查物件反馈是否说明内容含义。
   恰在角色眨眼时暂停配乐或中断音频，眼睛仍自然睁开；静音操作和跨页后表情继续正常。减少动态效果时保持稳定睁眼，原音轨和节拍位置保留。
9. 运行评审：桌面/手机截图无布局溢出，320×568 短屏与 768×1024 平板的模型不遮挡标题或按钮，滚动和尺寸变化后保持构图；减少动态效果、键盘、WebGL 降级、断网与存储不可用可用。性能证据注明硬件和浏览器，低性能设备有适当画质档位。
   从新上下文进入实验，首次滴色、显示键盘落点及击中第一块砖不会临时增加着色程序；明确区分初始化、首轮操作和持续运行的测量。九个实验进入下方操作区后，离屏首屏停止绘制；帧间隔统计不能代替真实手机与主观流畅度验收。
   在八个 WebGL 实验中反复操作“自动 / 精细 / 省电”，主场景和实验画布均落实相应分辨率与阴影；已暂停的游戏、颜料场和曝光记录保持一致，正在驾驶和着陆的进度延续。渲染器与场景对象身份保留，重复切换的程序、几何和纹理数量稳定。检查刷新、跨标签、窄宽屏变化、存储拒绝、延迟手动启动和无 WebGL；玻璃纸面的原生控件与折射图不重建。
10. 交付评审：公开参考有来源及核验状态，工程文档与源码一致，代码已提交并推送，实际部署版本可访问。最终验收仍须用户观察艺术效果。

首屏补充：冷启动关于页时，不请求房间、其他章节和九个实验的专属代码，仍能实际游泳及开启原创声音。桌面与窄屏在统一网络条件下记录 HTML、首个场景、声音合成和首次播放的时间，保留首次图形初始化样本；代理线上测量与桌面网络模拟分别报告。阻塞或拒绝目的页模块时，旧场景和音乐连续，失败后旧控件仍有效；连续改选最终进入最后一页，渲染器、角色与音源身份不变。首次加载失败仍能阅读和通过原生导航离开；所有 55 个入口及九个嵌入实验继续回归。

持续阻塞目的页模块时，原场景须保持可见且能实际触发活动，音乐继续，纸幕不能盖住画面等待。超过 12 秒后停止准备并提示，当前控件仍可用；进入另一个页面再放行旧请求，当前场景和 URL 不得变化，之后主动进入原目的地应正常完成。

在旧模块仍阻塞时连续改选，应直接到达最后目的地，不展示中间章节；前进后退也遵循真实历史位置。选择当前 URL 取消等待，提示已留在当前页面且控件正常。七种桌面、平板、短屏与横屏尺寸下，状态提示不遮挡标题、活动控制、声音或导航；键盘选择窄屏菜单后，等待阶段的焦点回到可见菜单按钮，实际转场完成后进入新标题。另看真实连续录像，确认等待与动作相连，辅助技术仍需人工验收。
